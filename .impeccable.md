## Design Context

### Users
Primary users are clinic operations staff and administrators managing daily queue, patient data, reminders, and reporting. They work in time-sensitive healthcare operations and need fast scanning, low-friction actions, and predictable behavior across pages.

### Brand Personality
Clinical, calm, efficient.

### Aesthetic Direction
Use a professional healthcare-admin visual language with strong clarity over decoration: semantic tokens, consistent spacing, readable density, and restrained emphasis. Optimize for both light and dark themes with stable contrast and clear focus states.

### Design Principles
1. Consistency first: shared table patterns, identical state handling, predictable action placement.
2. Readability over novelty: strong hierarchy, aligned numeric/data columns, clear empty/loading states.
3. Action clarity: row actions always right-aligned, icon actions keyboard-accessible and labeled.
4. Token discipline: rely on design-system colors/typography/spacing; avoid one-off hard-coded styles.
5. Operational resilience: robust pagination/search/sort contracts with null-safe rendering and responsive overflow handling.
